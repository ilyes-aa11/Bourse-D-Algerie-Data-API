Developer documentation

Bourse d'Algerie Data API

Read market companies, stock prices, trading session history, and session details from the Algerian Stock Exchange.

http://localhost:3000

Quick start

Install dependencies and start the server from the project root.

npm install
node src/main.js

# Open the documentation
http://localhost:3000/docs

The base URL in the examples is http://localhost:3000. Replace it with your deployed host. Every data endpoint uses GET and returns JSON.

Route index

GET/

Serves this documentation page.

HTTP 200 — text/html

GET/docs

Alias for the documentation page.

HTTP 200 — text/html

GET/stocks/:type

Latest stock prices filtered by all, main, bond, or sme.

GET/market/companies/:market

main, bond, or sme.

GET/sessions/:market/history/:year

Session history for main, bond, or sme.

GET/sessions/:market/details/:sessionID

Detailed securities data for one session and market.

Stocks

GET/stocks/:type

Returns the latest prices shown on the SGBV home page. Use all, main, bond, or sme for the type parameter. The response is an object keyed by stock symbol.

curl http://localhost:3000/stocks/all
curl http://localhost:3000/stocks/main
curl http://localhost:3000/stocks/bond
curl http://localhost:3000/stocks/sme

{
  "ALL": {
    "stockValue": "355,00",
    "stockVar": "0,00"
  },
  "CPA": {
    "stockValue": "2 300,00",
    "stockVar": "0,00"
  }
}

The complete response contains every stock currently published by SGBV.

Companies

Use one of the following market-specific paths. Each response has a companies array. The fields depend on the source table.

GET/market/companies/main

Main market listed companies.

curl http://localhost:3000/market/companies/main

    {
      "Code ISIN": "DZ0000010037",
      "Code": "ALL",
      "Company name": "ALLIANCE ASSURANCES",
      "Sector / Category": "ASSURANCE",
      "Nominal Value  DA": "380",
      "N of shares": "13 930 826"
    }
  ]
}

Bond-market securities and issuers.

Companies listed on the SME market.

Company field names are copied from the SGBV table headers and may change when the source website changes.

JavaScript example

async function getMainHistory(year) {
  const response = await fetch(
    `http://localhost:3000/sessions/main/history/${year}`
  )

  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`)
  }

  const data = await response.json()
  return data.sessions
}

Errors

Validation errors return 400. Upstream or server errors return 500.

Invalid year

GET /sessions/main/history/1998

HTTP 400
{
  "message": "Invalid year parameter must be between 1999 and 2026"
}

Invalid session ID

GET /sessions/main/details/not-a-number

HTTP 400
{
  "message": "A valid sessionID must be provided"
}

Internal server error

HTTP 500
{
  "message": "An internal server error has occurred"
}
